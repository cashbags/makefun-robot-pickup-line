One original pickup line a robot would use, in a single line — an entry for
the
[The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b?ref=qrg7fvky)
competition on [make.fun](https://make.fun/?ref=qrg7fvky).

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`:

> My actuators have one setting now: towards you.

47 characters. Actuators are a robot's muscles — the motors that move it —
and a robot whose every actuator points one way has given up all other
directions. Run it locally with `node main.ts /tmp/entry.txt` to see the
exact output.
